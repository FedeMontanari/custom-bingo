# Custom Bingo

## Description
Web app that allows you to create a custom Bingo card to share around with anyone.
#### Important Note
This app was [vibe coded](https://en.wikipedia.org/wiki/Vibe_coding) almost in its entirety. Bugs and spaghetti code are expected.
The goal was to experiment with AI and its capabilities for shipping usable software.

## Features
- Customizable Bingo grid
- Websockets for live game updates (win-lose)
